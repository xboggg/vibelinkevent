## How to use this file

1. **Pick one prompt block** (e.g. `Demo 1 → gallery-1.jpg`)
2. **Copy everything between the backticks** for that one image
3. **Paste into Midjourney / Imagen / Flux / Leonardo** and run
4. **Pick the best variation**, upscale if possible, download
5. **Rename to the filename shown** (`gallery-1.jpg`, `gallery-2.jpg`, etc.)
6. **Drop into the matching demo folder** at `vibelink/events/funeraldemoN/` — replaces the existing Picsum placeholder

Total: **60 generations** for the 10 existing templates. Templates 11–15 don't need galleries yet — they're flagged "Coming Soon" until we build them.

### Tip for consistent faces across the 6 gallery shots
If your tool supports it (Midjourney `--cref`, Flux IP-Adapter, Leonardo character reference, Imagen reference image), pass the **hero portrait you already generated** as the character reference for every gallery prompt. Saves you from getting a different-looking person in each photo.
