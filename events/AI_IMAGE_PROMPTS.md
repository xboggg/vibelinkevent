# AI Image Prompts — VibeLink Funeral Templates

Generate authentic Ghanaian imagery for the 15 funeral templates. Each prompt is written to work in Midjourney, DALL-E 3, Flux, Imagen, or Leonardo without modification.

---

## How to use

### Recommended tools (in order)
1. **Midjourney v6+** — most photorealistic faces; best for hero portraits. Use `--ar 3:4 --style raw --s 250`.
2. **Flux Pro / Flux Dev** — second-best for portraits, free/cheap on Replicate. Best for matching skin tones.
3. **Google Imagen 3** — excellent for posed elder portraits; free in Google AI Studio.
4. **Leonardo Phoenix** — strong for stylised gallery shots.
5. **DALL-E 3 via ChatGPT** — easiest, weakest photorealism on faces.

### Universal rules baked into every prompt
- All subjects are **specifically Ghanaian** (Akan / Ga / Ewe / Fante named where relevant)
- Skin tones: **dark to deep-medium brown** — explicitly stated to override default light-skinned bias
- Lighting: **natural window light** or **soft studio key** — never harsh
- Mood: **dignified, warm, contemplative** — never sad or distressed
- Composition: **head-and-shoulders** for hero portraits (3:4 ratio); **wider** for gallery
- Always include: `photorealistic, high detail, professional photography, no text, no watermark`
- For elders: include explicit age + describe weathered features so AI doesn't default to 40-something

### Negative prompts (paste into any tool that accepts them)
```
cartoon, anime, painting, illustration, low quality, blurry, distorted face, deformed hands, extra fingers, text, watermark, logo, signature, frame, border, cropped, tilted, harsh shadows, oversaturated, plastic skin, doll-like, american, european, light skin
```

### File naming convention
Save each generated image as:
- `<template-slug>-hero.jpg` (1200×1500 or 1500×1500)
- `<template-slug>-thumb.jpg` (1200×630 — for the /templates card)
- `<template-slug>-gallery-1.jpg` … `gallery-8.jpg` (varied aspects)

Then drop into the template's folder, replacing the Pravatar/Picsum placeholders.

## 4️⃣ Production tips

### To get consistent faces across hero + gallery
Most modern tools have "character consistency" features:
- **Midjourney:** Use `--cref [URL]` with your generated hero as reference
- **Flux:** Use IP-Adapter via Replicate or ComfyUI
- **Imagen:** Reference image in same prompt
- **Leonardo:** Character Reference feature

### To avoid AI face problems
- Always generate **multiple variations** (4+) — pick the best
- For elders, explicitly state "weathered skin, deep wrinkles, age spots, white hair" — AI under-ages by default
- For very dark skin, repeat "deep dark-brown skin tone" twice — AI lightens by default
- For groups: avoid "5 children" prompts (AI breaks on counting) — generate individual portraits + composite later

### Resolution & format
- Generate at **maximum resolution** the tool allows (Midjourney upscale, Flux 2048px)
- Export as **JPG quality 88–92** (smaller than PNG, no visible loss)
- Run through [Squoosh](https://squoosh.app) or `imagemin` to compress before deploy
- Target sizes: hero ≤ 200 KB, thumbnail ≤ 100 KB, gallery ≤ 150 KB each

### Time estimate
- 15 hero portraits × 4 variations + selection = ~3 hours
- 15 thumbnails × 2 variations = ~1.5 hours
- 15 templates × 6 gallery shots × character consistency = ~6 hours
- **Total: roughly a full workday** to generate the full image library
